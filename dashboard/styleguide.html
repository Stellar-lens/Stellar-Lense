LedgerLens Style Guide

Every component below is rendered with the real dashboard/styles.css — this page has no styling of its own beyond layout scaffolding for the swatches/bars. If it looks right here, it'll look right in the dashboard. See DESIGN_SYSTEM.md for usage guidance.

Color

Surfaces, text, and brand colors are theme-aware (toggle above). Risk-level tints (--low-bg/--medium-bg/--high-bg) back the score-pill and are the one set of colors this system reasons about semantically rather than by hue name.
