# Engineering Roadmap (short-form index)

This document links high-level workstreams and priorities. It is a coordination index, not the full plan.

Principles
- Prioritize production correctness, reproducibility, and security over feature breadth.
- Every cross-repo or schema change must include compatibility tests and rollout plans.

Workstreams (reference)
- Restore CI quality and enforce static analysis waivers (#607-#608)
- Delivery pipeline and artifact verification (#608-#609)
- Data lineage, migrations, and isolation tests (#615-#616)
- Executable architecture and contributor journeys (#624)

How to contribute
- File a focused child issue with acceptance criteria and tests.
- Link the child issue here and add reviewers for cross-cutting concerns.

This file is a lightweight index to ISSUE #625 and should be expanded by maintainers into a tracked roadmap document.
